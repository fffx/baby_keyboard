# BabyKeyboard Lock Fork

This is a fork of [fffx/baby_keyboard](https://github.com/fffx/baby_keyboard).

See the upstream repo for the original docs.

## Change in this fork

Adds **Patatap mode**.

When enabled, keyboard lock still blocks most keys, but allows:

- `A-Z`
- `Spacebar`

Caps Lock can be on or off.

This lets a toddler play [Patatap](https://patatap.com/) while keeping the rest of the keyboard locked.
